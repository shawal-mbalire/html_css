# html_css

HTML and CSS learning exercises.

## Contents

- **button.html** - Buttons with inline CSS, JavaScript events, custom elements, and styling basics
- **lesson2/** - Calculator app with HTML, CSS, and JavaScript
  - `index.html` - Calculator layout with button grid
  - `styles.css` - Calculator styling
  - `index.js` - Calculator logic

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Usage

Open any `.html` file directly in a browser:

```bash
open button.html
open lesson2/index.html
```
